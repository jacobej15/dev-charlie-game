What Does a Website Know About You?

IP-Address

What is it?

It acts like a mailing address for your computer or phone. It also tells other devices who is sending data and where the data needs to go.

When would you use it?

To connect a device to the internet.

Why would you use it?

To guide information packets across the internet. It can also be used to geo locate someone.

How Does JavaScript Access It?

Vanilla JS cannot directly access IPs due to security reasons, but client side scripts can access it.

Camera

What is it?

The camera lets a webpage request access to the device's camera and receive a live video stream.

When would you use it?

Video calls, QR/barcode scanners, photo/video apps, augmented reality, etc.

Why would you use it?

To let the user interact with the website using the camera.

How Does JavaScript Access It?

By using: "navigator.mediaDevices.getUserMedia()"
