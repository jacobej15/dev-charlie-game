# Expected Results
The page opens without errors.
The viewport width and height appear.
Resizing the browser updates the dimensions.
The console displays useful data.
Show Saved Information displays saved values.
The teams array is saved in sessionStorage.

# Demo
What it is: viewport detection and swipe interaction.
When you'd use it: responsive layouts and mobile navigation.
Why you'd use it: to make a site adapt to the visitor's device and input.
How it works: JavaScript reads viewport properties and listens for touch events.
What data you received: viewport dimensions and swipe direction/distance.
What you stored: visitor information, the last swipe, and the team array in session storage.
